## 👨‍💻 About Me

I'm an Electronics and Telecommunication Engineering student at **SPIT, Mumbai**, interested in digital hardware design, embedded systems, robotics, and intelligent systems.

I enjoy building projects that connect hardware and software, from FPGA-based processor design to ROS-controlled robots and AI-assisted safety systems.

- ⚡ Exploring FPGA design, Verilog, processor architecture and VLSI.
- 🔌 Developing embedded systems using microcontrollers and development boards.
- 🤖 Working with robotics, ROS and simulation environments.
- 🧠 Exploring AI/ML, computer vision and edge AI.
- 🛰️ Contributing to the Can7USAT student satellite team.
- 🏆 Participating in engineering competitions, robotics events and hackathons.
